## Critical Issues (Fix Now)

1. **`@tanstack/react-query` missing from `node_modules` and `package.json`** — `package.json` — 51 source files import `@tanstack/react-query` at runtime via double-quote syntax; the package is absent from both `dependencies` and `node_modules`. A production `next build` throws `Cannot find module '@tanstack/react-query'` and fails entirely. `@tanstack/react-query-devtools` is present in `devDependencies` but does not pull the main package. **Fix:** add `"@tanstack/react-query": "^5"` to `dependencies` and run `npm install`. — **16 weeks unresolved.**

2. **XSS via `dangerouslySetInnerHTML` in content preview** — `src/components/create/content-preview-modal.tsx:83` — `dangerouslySetInnerHTML={{ __html: content || "..." }}` renders AI-generated HTML with no sanitization. If an LLM produces `<script>alert(1)</script>` or `<img onerror="...">`, it executes in the victim's browser session. **Fix:** install `dompurify` + `@types/dompurify` and wrap with `DOMPurify.sanitize(content)`. — **13 weeks unresolved.**

3. **GraphQL schema introspection unauthenticated** — `src/app/api/graphql/route.ts:8` — The `yoga` handler is exported directly with no route-level auth guard: `export { yoga as GET, yoga as POST }`. Introspection queries (`__schema`, `__type`) enumerate the full API schema for any unauthenticated caller. **Fix:** set `introspection: process.env.NODE_ENV !== 'production'` in the yoga config inside `src/lib/graphql/schema.ts`. — **Unresolved.**

4. **Export jobs held in process-scope `Map`** — `src/app/api/export/route.ts:42` — `const exportJobs = new Map<string, ExportJob>()` stores state in a single Node.js process. Under multi-container Docker deployments (as configured in `docker-compose.yml`), a `GET /api/export/[id]` request routed to a different container will return 404 for 50–100% of polls. **Fix:** migrate job state to Upstash Redis (already wired in `src/lib/cache/`). — **11+ weeks unresolved.**

5. **CRON_SECRET fails-open when env var unset** — `src/app/api/cron/audit/route.ts:16-21` and 7 other cron routes — Each route checks `if (process.env.NODE_ENV === "development") return true;` BEFORE verifying the secret. Additionally, `/api/cron(.*)` is listed in `publicRoutes` in `src/middleware.ts`, meaning the cron middleware is the ONLY auth gate. If `CRON_SECRET` is unset in production, `undefined === undefined` evaluates to `true` and any caller can trigger expensive background jobs. **Fix:** add `if (!expectedSecret) return new Response('CRON_SECRET not configured', { status: 500 });` at the top of each auth helper. Confirmed in 8 routes: `audit`, `check-predictions`, `competitive-snapshot`, `geo-monitor`, `monitor`, `retention-purge`, `scheduler`, `social-scan`. — **Ongoing.**

6. **289 TypeScript `any` violations in production code** — Highest density: `src/lib/graphql/schema.ts`, `src/lib/browser-query/types.ts`, `src/lib/sub-agents/` — TypeScript `strict: true` is configured but `any` is used extensively via `: any`, `as any`, `<any>`, `any[]`. Count rose 8 this week (+3%). **Fix:** enable `"@typescript-eslint/no-explicit-any": "error"` in ESLint config and address incrementally starting with the API layer. — **289 violations, up from 281.**

7. **8 files exceed 1,200 lines (god-file list growing)** — `src/lib/graphql/schema.ts` (2,284), `src/app/dashboard/brands/page.tsx` (1,506), `src/lib/db/queries/competitor-queries.ts` (1,370), `src/lib/reports/schema-generator.ts` (1,273), `src/lib/billing/local-payments.ts` (1,255), `src/app/dashboard/settings/settings-client.tsx` (1,242), `src/lib/sub-agents/site-audit/src/services/ai-visibility-service.ts` (1,229), `src/app/admin/api-keys/page.tsx` (1,202) — New entry this week: `ai-visibility-service.ts`. **Fix:** extract sub-components and services; start with `schema.ts` (split into query/mutation/subscription files).
