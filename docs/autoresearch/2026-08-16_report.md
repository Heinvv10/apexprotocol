## Critical Issues (Fix Now)

1. **`@tanstack/react-query` missing from `package.json`** — 52 files import it; production build will crash — Add `@tanstack/react-query` to `dependencies` in `package.json` and install.

2. **XSS vulnerability in content-preview-modal** — `src/components/create/content-preview-modal.tsx:83` — `dangerouslySetInnerHTML={{ __html: content }}` with user-controlled `content` renders arbitrary HTML/script — Sanitize with DOMPurify before render: `dangerouslySetInnerHTML={{ __html: DOMPurify.sanitize(content) }}`.

3. **CRON spoofable `x-vercel-cron` header bypass** — `src/app/api/cron/competitive-snapshot/route.ts:43-45` — Anyone can POST with `x-vercel-cron: true` to trigger cron jobs without the secret; this header is not cryptographically verified — Remove the `x-vercel-cron` fallback; require `CRON_SECRET` always in production.

4. **`CRON_SECRET` fail-open in all 8 cron routes** — dev-mode bypass exists in every cron route (e.g., `src/app/api/cron/audit/route.ts:18-20`) AND `/api/cron(.*)` is in public middleware routes (`src/middleware.ts:36`) — Keep dev bypass but require `CRON_SECRET` be set in production via env validation at startup; fail hard if missing.

5. **GraphQL introspection unauthenticated** — `src/lib/graphql/schema.ts` (2,284 lines) — `graphql-yoga` defaults to introspection enabled; no auth check before schema queries — Add `maskedErrors: true` and disable introspection in production: `yoga = createYoga({ schema, graphqlEndpoint: '/api/graphql', plugins: [useDisableIntrospection()] })`.

6. **49% of mutation API routes lack Zod validation** — 104 of 212 POST/PUT/PATCH/DELETE routes have no input parsing — Pick top-traffic routes (brand, monitor, audit, recommendations) and add `z.object({...}).safeParse(await req.json())` guards.

7. **`competitor-queries.ts` god file** — `src/lib/db/queries/competitor-queries.ts` (1,370 lines) — Hard to maintain and test; violates single-responsibility — Split into `snapshot-queries.ts`, `analysis-queries.ts`, `metrics-queries.ts`.
