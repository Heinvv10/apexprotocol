## Critical Issues (Fix Now)

1. **`@tanstack/react-query` missing from `package.json`** — `package.json` — 53 files import it; only `@tanstack/react-query-devtools` exists in devDeps; production build will crash at import time — Add `"@tanstack/react-query": "^5"` to `dependencies` and run `npm install`.

2. **XSS via unsanitized HTML in `content-preview-modal`** — `src/components/create/content-preview-modal.tsx:83` — `dangerouslySetInnerHTML={{ __html: content }}` renders arbitrary HTML from DB/user input; attacker can inject `<script>` tags — Sanitize with DOMPurify before rendering: `DOMPurify.sanitize(content)`.

3. **Spoofable `x-vercel-cron: true` bypass in competitive-snapshot** — `src/app/api/cron/competitive-snapshot/route.ts:44-46` — Any external caller can set `x-vercel-cron: true` header and bypass authentication, triggering expensive DB/AI operations — Remove the `x-vercel-cron` fallback; rely solely on `CRON_SECRET` bearer token validation.

4. **GraphQL introspection exposed in production** — `src/app/api/graphql/route.ts` + `src/lib/graphql/schema.ts:2237` — `graphiql` is enabled with no auth guard; introspection reveals full schema, types, resolvers to any unauthenticated caller — Disable graphiql in production: `graphiql: process.env.NODE_ENV === 'development'`.

5. **Zero React.memo across entire codebase** — `src/components/**/*.tsx` — Heavy dashboard pages with frequent re-renders have no memoization; sidebar, nav, and card components re-render on every state change — Add `React.memo()` to stable leaf components (nav, sidebar, stat cards, chart containers).

6. **20 Recharts components imported statically** — `src/components/**/*.tsx` (20 files) — Chart libraries are large bundles; static import means every page pays the full recharts cost on initial load — Wrap recharts imports with `dynamic(() => import('recharts'), { ssr: false })`.

7. **186 of 305 API routes (61%) lack Zod input validation** — `src/app/api/**/*.ts` — Unvalidated API inputs allow malformed/oversized payloads to reach database queries and AI services — Add `z.object({...}).safeParse(body)` guard at the top of each unvalidated POST/PUT handler.
