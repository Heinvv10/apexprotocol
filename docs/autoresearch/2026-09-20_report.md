## Critical Issues (Fix Now)

1. **Missing `@tanstack/react-query` runtime dependency** — `package.json` — 53 files import `@tanstack/react-query` but it only appears in `devDependencies` as `@tanstack/react-query-devtools`. Production build will crash on import resolution. **Fix:** `npm install @tanstack/react-query` — `package.json` deps section. _Week 22+ unpatched._

2. **XSS via unsanitized `dangerouslySetInnerHTML`** — `src/components/create/content-preview-modal.tsx:83` — AI-generated content rendered directly into DOM with no sanitization. User can inject arbitrary HTML/JS via crafted AI response. **Fix:** Wrap with `DOMPurify.sanitize()` before rendering, or replace with a safe markdown renderer (e.g. `react-markdown`). _Week 19 unpatched._

3. **CRON endpoint spoofable via `x-vercel-cron: true` header** — `src/app/api/cron/competitive-snapshot/route.ts:43` — Anyone can trigger this endpoint by setting the `x-vercel-cron: true` header; no CRON_SECRET check. Other cron routes check CRON_SECRET correctly. **Fix:** Add `Authorization: Bearer $CRON_SECRET` validation before the `x-vercel-cron` fallback. _Week 6 unpatched._

4. **GraphQL introspection exposed in production** — `src/lib/graphql/schema.ts` — Default `graphql-yoga` config exposes full schema via introspection to unauthenticated callers, leaking the internal data model and all field names. **Fix:** Set `maskedErrors: true` and disable introspection in non-development environments via `graphql-yoga`'s `context` option.

5. **`graphql/schema.ts` god file at 2,284 lines** — `src/lib/graphql/schema.ts:1` — Single file holds all resolvers, types, and mutations. Extreme maintainability and merge-conflict risk. **Fix:** Split into domain modules: `brands.schema.ts`, `monitor.schema.ts`, `audit.schema.ts`, `content.schema.ts`, `recommendations.schema.ts`.

6. **196 of 305 API routes (64%) lack Zod input validation** — `src/app/api/` — Unauthenticated or authenticated inputs go unvalidated, enabling injection and unexpected server behavior. **Fix (rolling):** Start with high-traffic/mutation routes: `POST /api/v1/brands`, `POST /api/monitor/*`, `POST /api/content/*`.

7. **0 React.memo usage across entire component tree** — `src/components/` — Heavy re-render chains on dashboard pages with complex state. GEO score dashboard and brand monitor pages re-render all children on any state change. **Fix:** Apply `React.memo` to pure display components: KPI cards, chart wrappers, list items, recommendation cards.
